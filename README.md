# REDPLAY GAMES — PRO UI starter
مشروع Android مستقل بواجهة عربية داكنة/حمراء، بطاقات ألعاب، بحث، تصنيفات، مفضلة، تفاصيل، وحركات انتقال وتوهج.

## بناء APK
ارفع محتويات المشروع إلى GitHub مع الحفاظ على `.github/workflows/build-apk.yml`. من Actions شغّل REDPLAY Android Build. بعد نجاح المهمة نزّل artifact `REDPLAY-GAMES-debug-APK`.

## ملاحظات واقعية
هذه نسخة واجهة أولية محسّنة وليست نسخة Whacka المصدرية. لم يتم التحقق من روابط تنزيل الألعاب ولم تُضف صور ألعاب مرخصة أو خلفية إدارية أو قاعدة بيانات. يجب اختبار البناء على GitHub وإكمال هذه الأجزاء قبل النشر العام.


## واجهة وحركة محسّنة
أضيفت مؤثرات لمعان متحرك في واجهة البداية، دخول تدريجي لبطاقات الألعاب، توهج متحرك في صفحة التفاصيل، وحركة تفاعلية لأيقونات شريط التنقل. هذه تغييرات في كود الواجهة وليست ضمانًا لحجم APK معين.
